# 🔐 Cryptic - Advanced Password Security Suite

A sleek, modern, and aesthetic web application built with Streamlit designed to analyze password strength, estimate brute-force crack times, and generate ultra-secure customizable passwords.

![Python Version](https://img.shields.io/badge/Python-3.8%2B-blue?style=flat-square&logo=python)
![Streamlit](https://img.shields.io/badge/Streamlit-1.0%2B-red?style=flat-square&logo=streamlit)
![License](https://img.shields.io/badge/License-MIT-green.svg)

---

## ✨ Features

* **Real-time Password Analysis:** Instantaneous checks for entropy, estimated brute-force crack time, and overall security risk levels.
* **Advanced Password Generator:** Custom keyword injection, precise length adjustments, and comprehensive complexity toggles (uppercase, lowercase, digits, symbols).
* **Minimalist & Aesthetic UI:** Built with Streamlit to provide a fast, clean, and distraction-free user experience.

## 🚀 Getting Started & Local Installation

Follow these steps to set up and run the project locally on your machine.

### Prerequisites

Make sure you have **Python 3.8+** installed on your system. You can verify your Python installation by running:
```bash
python --version

```

### Step 1: Clone the Repository

Clone the repository to your local machine using Git:

```bash
git clone [https://github.com/kudepi/cryptic.git](https://github.com/kudepi/cryptic.git)
cd cryptic

```

### Step 2: Install Dependencies

Install the required Python packages using `pip` and the provided `requirements.txt` file:

```bash
pip install -r requirements.txt

```

### Step 3: Run the Application

Launch the Streamlit app locally with the following command:

```bash
streamlit run app.py

```

Once executed, Streamlit will automatically generate local and network URLs in your terminal (typically `http://localhost:8501`). Open this link in your web browser to interact with the application.
